This agent makes autonomous API calls to external services in a LangChain or ELIZA pipeline. Without policy, it could POST sensitive data to arbitrary endpoints, reach internal or cloud-metadata endpoints, or email results to an unbounded recipient list. This warranty.md restricts HTTP requests to allowlisted partner hosts and methods (fail-closed), denies listed private-network hostnames and credential strings as defense in depth, bounds email recipients and holds sends for approval, and requires a declared job type on every governed intent.
