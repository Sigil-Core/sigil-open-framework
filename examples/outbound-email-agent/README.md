This agent drafts and sends outreach email through a provider API (Resend, SendGrid, Gmail API) and reads prospect data from a CRM. Without policy, it could send unreviewed mail to anyone, blast internal broadcast lists, or run unbounded volume against a campaign. Outreach recipients are unknown in advance, so this warranty.md does not use a recipient allowlist; instead it holds every send for human approval, forces a recipient onto every send intent (declared recipient rules fail closed on a missing `to`), denies listed internal broadcast addresses, requires a declared job type and campaign on every intent, and caps daily send volume per campaign. Suppression lists and unsubscribe handling stay in the email provider.
