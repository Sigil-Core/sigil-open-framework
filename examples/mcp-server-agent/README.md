This agent reaches external tools through MCP servers and sends email on behalf of an operator. Without policy, a malicious or confused MCP tool call could delete a repository, run a destructive tool on any connected server, or email arbitrary recipients. This warranty.md allowlists the MCP servers and tools the agent may call (fail-closed on missing tool metadata and on unlisted servers or tools), blocks listed destructive tool patterns, holds email for human approval with bounded recipients, denies listed credential strings as defense in depth, requires a declared job type on every governed intent, and caps tool calls per task and per hour. Raw shell is deliberately not allowed: an MCP gateway agent does not need one.
