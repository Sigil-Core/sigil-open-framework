This agent reaches external tools through MCP servers, running shell, fetching web pages, and sending email on behalf of an operator. Without policy, a malicious or confused MCP tool call could wipe a disk, SSRF into cloud metadata, exfiltrate credentials in a request body, or email arbitrary recipients. This warranty.md blocks destructive shell commands, blocks requests to internal networks and metadata endpoints, prevents credential leakage, bounds email recipients, requires an allowlisted job type on every governed intent, and caps tool calls per task and per hour.
