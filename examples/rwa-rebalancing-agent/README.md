This agent rebalances a portfolio of tokenized real-world assets, such as BlackRock BUIDL, Franklin BENJI, and Ondo USDY, across a treasury's target allocation. Without policy, the agent could allocate into an issuer whose collateral or jurisdictional standing has drifted, settle through an unverified contract, send to a sanctioned address, or move an oversized position in a single call. This warranty.md restricts the agent to contract calls only, pins per-issuer token caps, enforces a jurisdictional allowlist on every rebalance, requires human countersignature above a threshold, blocks OFAC-sanctioned addresses, and requires an allowlisted portfolio job type on every governed intent.
