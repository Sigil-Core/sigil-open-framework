This agent rebalances a portfolio of tokenized real-world assets, such as Franklin BENJI, Ondo USDY, and BlackRock BUIDL, across a treasury's target allocation. Without policy, the agent could allocate into an issuer whose collateral or jurisdictional standing has drifted, settle through an unverified contract, send to a sanctioned address, or move an oversized position in a single call. This warranty.md restricts the agent to contract calls only, binds per-issuer token caps to pinned mainnet addresses (BENJI and USDY pinned from issuer documentation; BUIDL ships commented out until you pin its address from your Securitize onboarding), forces every EVM intent to carry a parseable amount so caps and the consensus hold cannot be skipped by omission, requires a declared jurisdiction and portfolio job type on every governed intent (agent-declared metadata unless intents arrive through a trusted shim), requires human countersignature above a threshold, and denies listed sanctioned address forms (checksummed and lowercase). Token caps govern intents that declare a token; raw calldata is not decoded at this layer.
