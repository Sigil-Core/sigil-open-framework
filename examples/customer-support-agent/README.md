This agent answers customer tickets, fetches knowledge-base pages, and sends email replies. Without policy, a prompt-injected ticket could make it auto-issue a refund, dump a customer table or SSN into an outbound reply, or blast an internal all-staff list. This warranty.md holds every email for human approval, bounds recipients to customer and support domains while blocking internal and all-staff lists, blocks refund execution from a ticket reply, denies PII and customer-table exfiltration via literal string markers, blocks mass-send, requires an allowlisted job type, and keeps execution limits low so one ticket cannot fan out.
