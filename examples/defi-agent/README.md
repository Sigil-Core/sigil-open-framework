This agent autonomously swaps tokens and deploys capital across DeFi protocols. Without policy, it could drain a treasury in one token transfer, route funds to sanctioned addresses, or accept undefined job types from an on-chain work marketplace. This warranty.md caps native ETH and USDC separately, pins USDC contract addresses so token caps bind to real deployments, forces every EVM intent to carry a parseable amount so caps and the consensus hold cannot be skipped by omission, allowlists chains, requires human countersignature above a threshold, denies listed sanctioned address forms (checksummed and lowercase), and requires a declared job type on every governed intent. Token caps govern intents that declare a token; raw calldata is not decoded at this layer.
