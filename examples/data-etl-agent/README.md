This agent runs a high-volume batch data pipeline, shelling out to extract, transform, and load steps, fetching source data over the web, and writing output files. Without policy, a bad query or injected step could drop a production table, truncate a warehouse, dump every row of a source table, or write over system paths. This warranty.md denies listed destructive SQL and shell strings at both the bash command layer and via custom rules (case-sensitive substrings, both casings listed), denies file writes to listed system and credential paths including expanded home-directory forms, denies a pathless file write outright, denies listed private-network hostnames and credential strings, requires a declared pipeline stage, and sets soft and execution limits sized for a high-throughput batch job. Note that bash remains a broad channel: it is governed only by the listed blocked substrings.
