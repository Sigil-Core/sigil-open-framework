This agent runs a high-volume batch data pipeline, shelling out to extract, transform, and load steps, fetching source data over the web, and writing output files. Without policy, a bad query or injected step could drop a production table, truncate a warehouse, dump every row of a source table, SSRF into cloud metadata, or write over system paths. This warranty.md blocks destructive SQL and shell at both the bash command layer and via custom rules, restricts file writes away from system directories, blocks SSRF endpoints, blocks mass exfiltration and credential strings, requires an allowlisted pipeline stage, and sets soft and execution limits sized for a high-throughput batch job.
