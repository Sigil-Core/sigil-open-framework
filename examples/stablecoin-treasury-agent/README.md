This agent manages an organization's stablecoin reserves, swapping and settling across USDC, PYUSD, and USDT to keep treasury positions balanced. Without policy, a compromised or drifting agent could move reserves into an unverified or de-pegged token, send funds to a sanctioned address, or drain the treasury in a single oversized transaction. This warranty.md pins each issuer's stablecoin to verified contract addresses, caps per-token and per-transaction amounts, allowlists chains, requires human countersignature above a threshold, blocks OFAC-sanctioned addresses, and requires an allowlisted treasury job type on every governed intent.
