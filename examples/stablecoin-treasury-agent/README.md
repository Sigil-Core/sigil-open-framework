This agent manages an organization's stablecoin reserves, swapping and settling across USDC, PYUSD, and USDT to keep treasury positions balanced. Without policy, a compromised or drifting agent could move reserves into an unverified token, send funds to a sanctioned address, or drain the treasury in a single oversized transaction. This warranty.md pins each issuer's stablecoin to contract addresses verified from issuer documentation, caps per-token and per-transaction amounts on token-declared intents, forces every EVM intent to carry a parseable amount so caps and the consensus hold cannot be skipped by omission, allowlists chains, requires human countersignature above a threshold, denies listed sanctioned address forms (checksummed and lowercase), and requires a declared treasury job type on every governed intent. Token caps govern intents that declare a token; raw calldata is not decoded at this layer.
